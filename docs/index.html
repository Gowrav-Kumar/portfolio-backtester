Portfolio BackTester

A small Next.js app to experiment with portfolio allocations and historical NAV data. This repository contains the app source.

Quick links

  • Run locally: npm run dev
  • Open the builder page: /builder (when running locally)

Publish to GitHub Pages

This project ships a lightweight static landing page under docs/. GitHub Pages can publish that folder as a site at <your-username>.github.io/<repo>.

After creating a GitHub repo and pushing the code, enable Pages from Settings → Pages → Branch: main / Folder: /docs.

# initialize repo (if you want me to run these, tell me)
